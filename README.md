# Lateli
An art marketplace where users can upload, browse, and buy artwork. Built as a scoped learning project, the goal is a working core flow (upload → browse → purchase).

## Tech Stack
**Frontend**
- React + TypeScript + Vite
- Tailwind CSS
- React Router
- @phosphor-icons/react

**Backend**
- Express / Node.js
- Prisma ORM
- MySQL (local)
- Multer (memory storage) for file uploads
- with Supabase storage for image files

## Out of Scope
Deliberately cut to keep the project shippable:
- Messaging
- Reviews
- Karma / reputation system
