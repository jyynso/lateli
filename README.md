# Lateli
An art marketplace where users can upload, browse, and buy artwork.

## Tech Stack
**Frontend**
- React + TypeScript + Vite
- Tailwind CSS
- React Router
- phosphor-icons

**Backend**
- PHP / Laravel
- Eloquent ORM
- MySQL (Dockerized)
- Laravel Sanctum (auth)
- Supabase Storage for image files
---
- built as a learning project.
